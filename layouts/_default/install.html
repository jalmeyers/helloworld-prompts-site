Installing the library as a skill lets Claude find and run these prompts for you. Instead of copying and pasting, you can say "run the meeting notes to follow-up prompt" or "what sales prompts do you have?"

A skill is a folder with a SKILL.md file that tells Claude what the skill is for and how to use it. This one also contains every prompt and tag on this site.

In the Claude app (web or desktop)

  1. Download {{ $name }}.zip (the latest release).
  2. In Claude, open Settings and find the Skills section.
  3. Upload the zip and make sure the skill is turned on.
  4. Start a new chat and ask: "What prompts are in the hello world library?"

If you don't see a Skills section, your workspace admin may need to enable skills (and code execution, which skills rely on).

In Claude Code

Clone the library, build the skill, and copy it into your personal skills folder:

git clone {{ $repo }}.git
cd {{ $name }}
./scripts/build-skill.sh
mkdir -p ~/.claude/skills
cp -r dist/{{ $name }} ~/.claude/skills/

To share it with everyone working in a project, copy it into that project's .claude/skills/ folder instead.

Updating

When new prompts are released, download the zip again and re-upload it (or git pull and rerun the commands above). See all releases.
